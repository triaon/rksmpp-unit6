# Задание 6: Доработанное клиентское приложение “Nobel Prize API”
Доработать клиентское приложение из Задания 2 на работу с собственным API сервером из Задания 5. Весь функционал приложения остается таким же.

Функционал приложения:

Приложение на Ktor Client + Clean Architecture, которое:
- авторизуется на собственном сервере (POST /login, JWT-токен);
- показывает список лауреатов Нобелевской премии, полученный с собственного сервера (GET /prizes);
- позволяет фильтровать по году и/или категории (GET /prizes?year=...&category=...);
- при клике на лауреата открывает экран с подробной информацией;
- позволяет добавить премию в избранное или убрать её оттуда и посмотреть список избранного (GET/POST/DELETE /users/me/prizes, GET /users/me);
- API: собственный сервер из задания 5, http://10.0.2.2:8080 (для эмулятора это localhost компьютера; cleartext-трафик разрешён только для 10.0.2.2 через network_security_config).

Требования к приложению:
1. Экран списка лауреатов (LazyColumn):
   - Для каждого элемента: год премии; категория; имя лауреата (fullName); краткое описание (motivation) — первые 100 символов.
   - Поля для фильтра: год и категория (выпадающий список).
2. Экран детализации лауреата:
   - Полное имя;
   - Год и категория;
   - Полное описание (motivation);
   - Страна (birthCountry / birthPlace);
   - Фото (поле portraitUrl из ответа сервера).
3. Clean Architecture.

Обработка состояний: Loading (CircularProgressIndicator); Success (список); Error (текст ошибки + кнопка «Повторить»).
